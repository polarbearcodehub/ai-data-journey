# AI Data Journey — 从数据工程到 AI 数据工程

## 🧭 三层能力栈（我的技术叙事）

```
┌─────────────────────────────────────────┐
│  智能消费层  Data Agent · GraphRAG       │  ← 业务怎么用上知识
├─────────────────────────────────────────┤
│  知识组织层  本体建模 · 知识图谱          │  ← 数据怎么变成知识
├─────────────────────────────────────────┤
│  数据底座层  入湖 · 数仓 · 治理（3年）    │  ← 数据怎么进来、怎么治好
└─────────────────────────────────────────┘
```

- **数据底座**：已具备——数据入湖、数据开发、数据治理（制造业场景）
- **知识组织**：学习中——本体 Schema 设计、三元组抽取、图谱构建
- **智能消费**：学习中——RAG、GraphRAG、Data Agent（NL2SQL + 工具调用）
